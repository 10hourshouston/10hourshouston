------------------------------------------------------------------
THE TYPEFACE — PLEASE READ
------------------------------------------------------------------
The mark is set in CHAKRA PETCH, released under the SIL Open Font
License 1.1. This means it is free to use commercially, free to
install on as many machines as needed, and free to embed in print
and digital work. No licence needs to be purchased.

The TTF files are in "03 Fonts". Install them before opening the
editable SVG. The full licence text is included alongside them, and
the family can also be downloaded from:

    https://fonts.google.com/specimen/Chakra+Petch

Please do not substitute a lookalike font. The mark's proportions
are derived from this specific typeface.


------------------------------------------------------------------
WHICH FILE TO USE
------------------------------------------------------------------
01 Vector (SVG) — USE THESE WHEREVER POSSIBLE
  Type is converted to outlines, so these render correctly whether
  or not the font is installed, and scale to any size without loss.

  Primary ............ the default. Ink on transparent.
  Knockout ........... reversed out of a dark panel.
  Accent ............. ember tagline. Covers and titles only.
  1Color-Black ....... single-plate print, vinyl, embroidery.
  Wordmark-Only ...... small sizes, avatars, favicons, merchandise.
  EDITABLE-live-text.. live text, for amends only. Needs the font.

02 Raster (PNG) — CONVENIENCE ONLY
  Supplied at 1000px and 3000px wide. Primary, Accent, and
  Wordmark-Only have transparent backgrounds.
  Use the SVGs instead for anything printed or anything that will
  be scaled. These are for slide decks, social, and quick previews.

03 Fonts
  Chakra Petch TTFs (Regular, Medium, SemiBold, Bold) + OFL licence.


------------------------------------------------------------------
THE ONE THING THAT MATTERS MOST
------------------------------------------------------------------
The tagline "New Wells. New Frontiers" is letterspaced at
+136/1000 em. That value is not arbitrary and not decorative — it
is calculated so the tagline's width matches the wordmark's exactly,
flush on both the left and right edges. That alignment is the whole
idea of the lockup.

If the tagline wording ever changes, the tracking must be
RECALCULATED so the two lines still align. Do not retype new words
at the same tracking value and assume it will hold.


------------------------------------------------------------------
QUICK REFERENCE
------------------------------------------------------------------
Wordmark ....... Chakra Petch Bold (700), all caps, tracking -5/1000 em
Tagline ........ Chakra Petch Regular (400), tracking +136/1000 em
Clear space .... half the cap height on all four sides
Minimum size ... 40 mm wide in print / 180 px wide on screen
                 (below that, use Wordmark-Only)

Ink ............ #14161A
Ember .......... #9E3B14
Paper .......... #FBFAF8

CMYK values in the specification are arithmetic conversions for
guidance. For a commercial print run, match from a physical proof.
Do not pick a Pantone number off a screen.
